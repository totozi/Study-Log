### 3. 'Activity' 탭 활용
이미지(image_1158bc.png)의 오른쪽 사이드바를 보시면 **`Activity`**라는 항목이 있습니다. 
*   이 버튼을 클릭하면 잔디 형태는 아니지만, 언제 어떤 커밋이 일어났는지 타임라인 형태로 한눈에 볼 수 있는 페이지로 이동합니다.
